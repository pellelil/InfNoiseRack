# Increment/Decrement Offset
![Features](https://img.shields.io/badge/Polyphonic-Input--Output-green.svg?style=flat-square)<br>
Internally, the module maintains an offset value for each channel (defaulting to 0V). At the top of the module, you'll find a value knob and corresponding CV input for setting the increment/decrement amount. This input supports both monophonic signals (applying the same value to all channels) and polyphonic signals (applying individual values per channel).

Whenever the module receives an increment trigger or you press the manual increment button, the specified value is added to the internal offset for each channel. Likewise, when it receives a decrement trigger or you press the decrement button, the value is subtracted from the internal offset for each channel. Pressing the reset button, or sending a reset trigger, sets all internal offsets back to 0V. If you in the same cycle sends both a Reset-signal and a Inc- or Dec-signal the Inc/Dec-signal is ignored (hence the internal offset will reset to 0V). Likewise sending both an Inc- and Dec-signal in the same cycle, both will be ignored *("X+Y-Y = X")*.

On each cycle, the current offset is added to the CV signal connected to the input at the bottom of the module. Like other Infinite-Noise modules, the output is clipped by default to the range −12V to +12V. If you expect the signal to exceed this range, you may want to disable the default clipping via the context menu. The module supports both monophonic and polyphonic inputs and will output the same number of channels as it receives.

![Screenshot of IncDecOffset](module/IncDecOffset.png)

**TIP**: Aside from the selected clipping range, the module will continue to increment or decrement its internal offset each time it receives an Inc- or Dec-trigger. To prevent overflow, this offset is internally wrapped (dividable by 10), though it can still exceed the typical −12V to +12V clipping range. To keep the output under control, you may want to disable the built-in clipping and instead process the signal externally. For example, you can pass the output through a [Clamp 4](Tweak.md#clamp-4po) module to define a custom min/max range (from −10V to +10V), or through a [Fold](Fold.md#foldpoq) module set to **Wrap**. In wrap mode, values exceeding the range are wrapped back into it—for instance, an input of 108V wrapped within 0V to 10V will result in 8V. The Clamp module gives you precise control over the output range, while the Fold module provides fixed bipolar (−5V to +5V) or unipolar (0V to 10V) ranges. If needed, you can further adjust the signal using one of the [Tweak modules](Tweak.md) or an [Auto-scale 4](Tweak.md#auto-scale-4p) module to scale it to your desired range.

**TIP**: While the **Value** input supports polyphonic signals, the **Increase**, **Decrease**, and **Reset** triggers are monophonic. If you need to increment or decrement only specific channels, you can control this through the Value input. For example, you can route a polyphonic signal through a [Poly-Tweak Mk II](PolyTools.md#poly-tweak-mk-iip) before feeding it into the Value input of the IncDecOffset module. By using the **Disable** feature in **Value mode** (with disabled channels set to 0V), a polyphonic gate signal can determine which channels are disabled. When an increment or decrement trigger is received by the IncDecOffset module, all channels are processed—but any disabled channels will effectively change by 0V, leaving them unchanged *("X+0 = X")*.
