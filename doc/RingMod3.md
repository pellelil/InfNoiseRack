# Ring Modulator 3(pq)
This 2HP module contains three sections, each with an **A** and **B** input. The two signals are multiplied together, and the product (the result of the multiplication) is sent to the section’s output. If you only input an **A** signal (A1) in the first section and no **B** signal (B1), then B1 will be normalized to A1, meaning the first section will do a ring modulation of the same signal. In sections 2 and 3, the **A** input is normalized to the output of the previous section, and the **B** input is normalized to the **B** signal connected to the previous section. This means that if you connect a **B** input only to the first section (B1), all three sections will use the same **B** signal. 

The module supports and generates polyphonic signals when polyphonic inputs are provided. Within each section, you can mix monophonic and polyphonic signals—in this case, each channel of the polyphonic signal is multiplied by the same monophonic signal. If you connect two polyphonic signals to the same section, they should ideally have the same number of channels. In all cases, the section will output the same number of channels as the input with the highest channel count in that section.

Next to each of the six inputs (A/B 1–3), there are two small indicator lights showing how the signal is processed before the A and B inputs of that section are multiplied. The **top light** indicates how the input signal is attenuated (scaled down). By default, it illuminates **green** for all B-inputs, meaning all B-inputs are divided by 10 (effectively converting a unipolar 0–10 V signal into a 0–1 range). Using the context menu, you can change this scaling to a division by 5—indicated by a **yellow** light—which converts a bipolar −5 V to +5 V signal into a −1 to +1 range. Scaling can also be disabled entirely, in which case the light will be dim. By default, all **B inputs** are set to divide by 10. 

*Ideally either A or B should be scaled-down according to it's input-range to ensure the generated output will not exceed the default -12V to +12V clipping-range. Otherwise if you do need higher outputs, the default clipping range can be disabled using the context menu.*

The **bottom light** indicates how negative input values are handled. By default (when this light is dim), input values retain their original sign—negative values remain negative. This behavior can be changed via the context menu so that negative values are converted to positive values (indicated by a **blue** light), or clamped to 0 V (indicated by a **red** light). By default, all inputs preserve their sign, so this second light defaults to dim.

The context menu includes options for configuring scaling and the handling of negative values separately for each of the six inputs (A/B 1–3). It also provides menu items that allow you to apply these settings simultaneously to all three **A** inputs or all three **B** inputs. As explained above the two lights next to each input, illustrate which modes are selected for each input.

**TIP**: If you only feed a signal into **A1** (not **B1**), the **AB1** output will produce the signal ring-modulated (multiplied) by itself. If you leave the inputs of the next two sections unconnected, each section will again ring-modulate the previous result using the same signal normalized from **B1** (essential from **A1**). As a result, if only inputting a signal to **A1**, the **AB3** output will effectively produce the original signal ring-modulated by itself three times in succession. 

**TIP**: If you feed the same unipolar signal (0–10 V) into **B1**, it can be used to attenuate three separate signals connected to **A1–A3**. If you instead connect separate unipolar signals to **B2** and **B3**, each section can perform its own independent attenuation. Since all inputs support polyphonic signals, you can even attenuate each channel individually by supplying polyphonic control signals (basically it's **amplitude modulation**).

**TIP**: As explained in the previous tip, the module can be used to attenuate signals. However, since the inputs are not clamped, it can also be used to amplify them. For example, the **B** inputs are divided by 10 by default, so if you input **20 V** into a B input, the signal on the **A** input will be multiplied by **2** (effectively amplifying it by 2x). *Remember that outputs are by default clamped in the range -12V to +12V, so if you need to output values exceeding this range, you must change/disable clipping via the context menu*.

Likewise, if you input a negative signal (e.g., **−10 V**) into the **B** input, the signal on the **A** input will be inverted. *Using the On/Off knobs on a [On/Off Switch](Switch.md#onoff-switchp) you can toggle it between either outputting -10V or +10V if you want to toggle between invert/not-invert. Likewise not supplying A- or B-inputs to a [Bernoulli Switch](Switch.md#bernoulli-switchp) you can use it's context menu to normalize A to -10V and B to +10, so that its probablility-setting can be use to toggle between invert/not-invert*.
