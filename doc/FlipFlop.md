# Flip-Flop
![Features](https://img.shields.io/badge/Polyphonic-Input--Output-green.svg?style=flat-square)<br>
The Infinite-Noise Flip-Flop module integrates **three different types of flip-flops** into a single module. In the top you find the 2-way switch which lets you pick either **T-mode (Toggle Flip-Flop)** or **D-Mode (Data Flip-Flop)**. However thanks to the dedicate Set- and Reset-inputs **SR-mode (Set/Reset Flip-flop)** is available at all time (whether the 2-way switch is in the T- or D-position).

A flip-flop stores and toggles between two states, outputting either High- (10V by default) or Low-gate (0V by default). The key difference between the three modes lies in how the module determines when the output should change. When switching between T- and D-modes, one of the two indicator lights above the "T/D" label illuminates, signifying the active mode.

Below the mode switch, there are two main inputs. The first input, labeled T/D, changes its function depending on the selected mode. The second input acts as a Clock (trigger). The Clock input normalizes to the "T/D" input, however this is only usefull when in Toggle-mode (see below). 

Below the T/D and Clock inputs you will find the **dedicated Set and Reset inputs**, each with a small manual push-button. When inputting a high-gate or pressing the small push button for **Set**, the Q output will be set high, and likewise inputting a high-gate or pressing the small button for **Reset**, the Q output will be set low. While the Set or Reset input is high (or their buttons are pressed) **SR-mode takes priority** and the T/D and Clock-inputs are ignored. If both the Set and the Reset inputs are high at the same time the module goes into an **undefined state** (described further down).

By default, the module is **enabled** and will react to inputs, but you can control whether it is enabled using the "En/Dis" (Enable/Disable) input. A small toggle button next to this input determines whether it functions in gate mode or trigger mode. In gate mode, the module is disabled while receiving a high gate and enabled when the gate is low (however this can be swapped using the context-menu). In trigger mode, each incoming trigger toggles the module between enabled and disabled states. A green light above "En" indicates when the module is enabled, while a red light above "Dis" signals that the module is disabled. When no cable is attached to the En/Dis port, the module will be enabled at all time. While **disabled** the T/D-, Clock-, Set- and Reset-inputs are all ignored. 

At the bottom of the module, there are three output ports. The **Q** output is the primary flip-flop output, and toggling between high and low gates based on the active mode. The **!Q** Output provides an inverted version of "Q", meaning it outputs a low gate when "Q" is high and vice versa. **ChQ** is a trigger output, and it fires each time Q toggles from low-to-high or high-to-low. *Like many other Infinite-Noise modules, at least one of these output needs to be connected for the module to function.*

Most inputs/outputs can support/generate polyphonic signals, so the Flip-Flop can process up to 16 channels which can flip-flop individually. You can mix monophonic and polyphonic inputs (e.g. have a **polyphonic Set-input** which can set channels individually and have a **monophonic Reset-input** to reset all channels at once). If you do supply multiple polyphonic inputs they should ideally have the same number of channels. The **enable-input only supports monophonic signals**, hence all channels will be set as enabled/disabled based on this monophonic signal.

## T-Mode (Toggle Flip-Flop)
In Toggle mode, the T/D input serves as the "Toggle" input. Each time the module detects a clock-trigger, it checks the toggle input. If the toggle input is high at that moment, the Q output toggle its state—if it was high, it becomes low, and vice versa. If the toggle input is low while receiving the clock-input, the Q output remains unchanged. Again, the "!Q" output mirrors the inverted state of "Q". *As mentioned above, the T/D and Clock-inputs are ignored while the module is in the disabled state or the Set- or Reset-input are high.*

As indicated by the arrow-head, if you don't input a signal into the Clock port it will be normalized to the input-signal inserted into the "T/D" port. This nomalization is not very usefull when the module is in D-mode. However, in T-mode it enables you to only input a single signal into the the "T/D" port. Every time you input a high-gate/trigger it will toggle both the Q and !Q outputs, and fire the ChQ trigger-output.

## D-Mode (Data Flip-Flop)
In Data mode, the T/D input functions as the "Data" input *(the module function like S&H for gates)*. When the module detects a trigger on the clock input, it "samples" the Data input (as a gate). If the data input is high (by default 1V or more), the "Q" output is set to high; otherwise, it is set to low. The "!Q" output always provides the inverse of the "Q" output. *As mentioned above, the T/D and Clock-inputs are ignored while the module is in the disabled state or the Set- or Reset-input are high.*

## SR-Mode (Set/Reset Flip-Flop)
To use the SR-mode you don't need to connect any signal to the T/D- nor Clock inputs, however you should connect both an input to the Set and Reset-ports. When a high Set-gate is received the Q output will be set to high, and when a high Reset-gate is received the Q output will be reset to low. If both inputs are low, the output remains unchanged. However, if both Set and Reset are high at the same time, the module enters an **undefined state**. You can configure how the module should behave in this state using the context menu, with the default behavior being that the "Q" and "!Q" outputs remains unchanged until the undefined condition is resolved. Next to the "Q" label (near the Q output) a red light will illuminate while the undefined state is active. Once the conflict is resolved, the module resumes normal operation. *The Set and Reset inputs/buttons are ignored while the module is in the disabled state.*

**TIP**: While not the main purpose of the Flip-Flop, it can be used as a clock-divider. While in T-mode if you feed a clock into the T/D-input, the Q-output will work as a "/2" division of the input-signal. When using the Flip-Flop as a clock-divider the !Q output will function as a divided clock that is "shifted half a clock" compared to the Q output.

**TIP**: When using the module in T- or D-mode the Set- and Reset-buttons can be used to dial-in an initial state of Q. Likewise, even though using the module primarily in T- or D-mode, the Set- and/or Reset-inputs can be used to force a Set or Reset if/when you need. But remember that the Set/Reset inputs take priority, so while either of these are high, the T/D- and Clock inputs are ignored.

**TIP**: Many of the Infinite-Noise modules can use both gate- and trigger-inputs like the Enable/Disable input on the Flip-Flop itself, as the small button next to the En/Dis-input lets you toggle between gate- and trigger-mode. You might have a module-input that only accept gate signals, but you would like to control it with triggers. If you simply want to use succesive triggers to toggle the gate high/low, you can feed your trigger signal into the T/D-input while the module is set to T-mode. Each trigger-input will then toggle the Q-output between high and low. Alternative if you want a specific trigger to set the gate high, and another to se the gate low, you would instead connect your 2 trigger-signals to the Set- and Reset-inputs.
