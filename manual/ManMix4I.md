# Manuel Mix 4 Mk I
![Features](features/Polyphonic-Input--Output-green.svg)
![Features](features/Attenuate-2x-green.svg)
![Features](features/Mix--mode-Unity--Averaging-green.svg)<br>
The Manual-Mix4 Mk I is a compact, 2HP 100% manually controlled mixer featuring four inputs and one mix output. Each input has an individual mix knob that allows amplification within a range of 0% to 200%, with the default setting at 100%. At the top of the module there is a master-mix knob, which controls the overall amplification of the mixed output, also adjustable between 0% and 200%. This module supports polyphonic signals, but if inputs contain different numbers of channels, the output will adopt the highest channel count among them. If mixing monophonic and polyphonic signals, the monophonic signal will be applied equally to each polyphonic channel. However, if multiple polyphonic signals are used, they should ideally contain the same number of channels for proper mixing. *Some general info regarding the Mix modules are listed in [Common Mixer features](commonMixer.md).*

Each of the four mix knobs can be set to **inverted** amplification via the context menu (a small red light beside the knob indicates inversion). The module supports **unity** and **averaging** mix modes (mix-mode button: unpressed/black = Unity, pressed/blue = Averaging). 

![Screenshot of Manual Mix-4 Mk I](module/ManMix4I.png)

**TIP**: ManMix4 Mk I has manual knobs only—no amplification CV inputs. If you need CV-controlled mixing levels, use [Manuel Mix 4 Mk II](ManMix4II.md) (mono) or [Manuel Mix 4 Stereo](ManMix4st.md) (stereo). If you only need to amplify the mixed output using CV, you can feed the output to a [VCA-2](VCA2.md) module.

Other mixer modules: [Manuel Mix 4 Mk II](ManMix4II.md), [Manuel Mix 4 Stereo](ManMix4st.md), [Matrix Mix 5x5](MatrixMix5x5.md), [Matrix Mix 4x4 Stereo](MatrixMix4x4Stereo.md).
